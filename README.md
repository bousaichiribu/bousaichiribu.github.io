# 防災地理部ウェブサイト

中高生が地域を歩き、声を聞き、地図を囲みながら、地域の未来と事前復興を考える「防災地理部」の公式ウェブサイトです。

## ページ構成

- 表紙：理念、年間活動、参加高校への案内
- 参加高校：2025年度の中心的な参加校
- 活動記録：2022年度以降の年度別アーカイブ
- 2025年度：東日本大震災復興視察の記録
- 防災地理部について：活動理念、進め方、問い合わせ先

## ローカルでの確認

```bash
npm install
npm run dev
```

公開用ビルドの確認は `npm run build`、自動確認は `npm test` で実行できます。

掲載用画像は `public/images/`、元写真は `assets/originals/` に保存しています。
