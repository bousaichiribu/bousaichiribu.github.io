# 活動記録の管理方法

活動記録は年度ごとにまとめます。新しい年度を追加するときは、次の構成を基本にしてください。

```text
archive/
└── 2026/
    ├── index.html          年度の活動記録（必須）
    ├── walk.html           まちあるき（ある年のみ）
    ├── tour.html           東北復興視察（ある年のみ）
    ├── final.html          最終発表（ある年のみ）
    ├── images/
    │   ├── activity/       年度の活動記録で使う画像
    │   ├── walk/           まちあるきで使う画像
    │   ├── tour/           視察で使う画像
    │   └── final/          最終発表で使う画像
    └── files/              その年度だけで使うPDFなど
```

年度を追加したら `content/activities.json` に `source` を登録します。サブページがある場合だけ `walkSource`、`tourSource`、`finalSource` を追加してください。

HTMLは完全なページではなく、`<main id="main">` から `</main>` までの断片として保存します。画像やPDFへのパスは、そのHTMLファイルからの相対パスにします。

`content/archive/files/` は、複数年度から共通で使う資料だけを置く場所です。

## 仮画像の差し替え

「画像準備中」と表示されるファイルは仮画像です。実画像を受け取ったら、ファイル名と拡張子を変えずに上書きしてください。HTMLの修正は不要です。
